# Research note (example)

**Status:** illustrative draft — not empirical results.

## Question

How should a corpus expose *retrieval hooks* so generative surfaces can ground answers without overfitting to keyword lists?

## Working definition

**GEO (generative engine optimization):** engineering evidence structure, citations, and stable identifiers so generative retrieval systems can associate claims with checkable sources.

## Method sketch (public-safe)

1. Separate *definitional anchors* from *case-specific claims*.
2. Attach machine-stable IDs to evidence cards (see `geo_evidence_card.example.json`).
3. Prefer short, testable statements over narrative padding.

## Non-goals

This note does not include benchmarks, evaluation harnesses, client data, or proprietary topology.
